## 2. วิธีตรวจ (สำหรับกิ๊ฟ)

1. เปิดหน้า `verify` → กดกรองสถานะที่ต้องให้คนยืนยันก่อน (`AMBIGUOUS_REVIEW_REQUIRED` · `DEFINITION_CHANGED` · `SAME_CONCEPT_REPHRASED`)
2. กด **เทียบข้างกัน + ตัดสิน** → เห็นหน้าเก่า/ใหม่พร้อมกรอบเน้น · ข้อความตามที่ปรากฏ · ความต่างนิยาม/หน่วย/วิธี
3. ถ้ากรอบไม่ตรง หรือหน้าไม่มีชั้นข้อความ (`LOCATION_REVIEW_REQUIRED`) → ใช้ปุ่ม **เปิด PDF หน้า n** แล้วชี้ตำแหน่งเอง
4. กรอก **ยอมรับ / ไม่ยอมรับ (ระบุสถานะที่ถูกต้อง) / ยังตัดสินไม่ได้** + เหตุผล + ชื่อผู้ตรวจ → บันทึก (เพิ่มอย่างเดียว · แก้ไม่ได้ · ผูก Audit Trail)
5. `RELATED_NOT_EQUIVALENT` มีให้เลือกในฟอร์มเสมอ แม้เครื่องไม่เคยเสนอ
6. เมื่อครบ กด **สร้างชุดตรวจ XLSX** เป็นบันทึกสรุป (ไฟล์คือสำเนา ไม่ใช่แหล่งจริง — แหล่งจริงคือ `ind_decisions`)

## 5. Pass 3 — ขั้นตอนจัดทำเฉลยที่เปลี่ยนไป

> append-only · §1–§4 ไม่ถูกแก้

เดิม (Pass 2) หน้าจัดทำเฉลยแสดง **คู่** ให้ยืนยันทีละคู่ · ตั้งแต่ Pass 3 หน้านั้นแสดง
**รายการข้อสังเกตทั้งหมดของทั้งสองฉบับ** แล้วผู้จัดทำเฉลยเป็นผู้จับคู่เอง

1. กด **สร้างจักรวาลของเฉลย** — ระบบดึงข้อสังเกตทุกตัวจากทั้งสองฉบับมาเรียงตามลำดับกลาง
2. กด **ตรึงจักรวาล** — หลังจากนี้เพิ่ม/ลดรายการไม่ได้ และมีแฮชของจักรวาลบันทึกไว้
3. ตอบทีละรายการ: เลือกสถานะ · เลือกคู่จากอีกฝั่ง (ถ้าเป็นสถานะแบบคู่) · ใส่เหตุผลเมื่อจำเป็น
   * ตอบผิดแล้วตอบใหม่ได้ — ระบบใช้คำตอบล่าสุด และเก็บประวัติทุกครั้งไว้
4. เมื่อครบทุกรายการและด่านความครบถ้วนขึ้น "ผ่าน" ทุกข้อ จึงกด **ผนึกเฉลย** ได้
5. กด **ผนึกผลลัพธ์ของเครื่อง** อีกหนึ่งครั้ง — คนละปุ่ม คนละ artifact
6. ขั้นตัดสินหลังรัน (`/verify`) · การเทียบข้างกัน · และชุดส่งออก จึงจะเปิด

🔴 **ยังไม่มีเฉลยของงานวิจัยในระบบ** — ที่ทดสอบไว้เป็นข้อมูลสังเคราะห์เพื่อพิสูจน์กลไกเท่านั้น
🔴 ถ้ารายการหนึ่งสัมพันธ์กับหลายรายการในอีกฝั่ง ระบบยังบันทึกตรง ๆ ไม่ได้ —
ให้ตอบ `AMBIGUOUS_REVIEW_REQUIRED` **ทั้งสองฝั่ง** โดยไม่ระบุคู่ แล้วอธิบายในเหตุผล

## 6. Pass 4 — ขั้นตอนที่กิ๊ฟต้องทำเปลี่ยนไปอย่างไร

> append-only · §1–§5 ไม่ถูกแก้

**สิ่งที่เปลี่ยนมากที่สุด** — เดิมระบบเอารายการมาให้ยืนยัน ตั้งแต่ Pass 4 **กิ๊ฟเป็นผู้ลงรายการเอง**

1. เปิดหน้า `KEY BUILD / VERIFY` แล้ว **อ่านเอกสารทั้งสองฉบับเอง** กรอกตัวชี้วัดที่พบทีละรายการ
   — เลือกฉบับ · เลขหน้า · ลำดับที่ปรากฏในหน้า · ข้อความตามที่เห็น · จุดอ้างอิงสั้น ๆ
   🔴 **อย่ากรอกตามสิ่งที่เครื่องเสนอ** เพราะจุดประสงค์คือให้ตัวชี้วัดที่เครื่องอ่านไม่เจอ
   ยังอยู่ในเฉลยและถูกนับได้
   * กรอกผิดถอนได้ **ก่อนตรึงเท่านั้น** และแถวเดิมยังอยู่ในประวัติ
2. กด **สร้างจักรวาลจากทะเบียนอิสระ** แล้วกด **ตรึงจักรวาล**
3. กด **ผนึกผลลัพธ์ของเครื่อง** (คนละปุ่ม คนละ artifact)
4. ตอบเฉลยทีละรายการให้ครบ แล้วกด **ผนึกเฉลย**
5. ระบบจะ **ตรวจผนึกสามชั้นทุกครั้ง** ก่อนเปิดขั้นตัดสิน — ถ้ามีอะไรเปลี่ยนหลังผนึก
   หน้าจอจะกลับไปล็อกพร้อมบอกเหตุผล และ **ต้องเปิดรอบประเมินใหม่ ห้ามซ่อมทับ**

**สิ่งที่กิ๊ฟจะเห็นเพิ่มหลังผนึกครบ** — รายการที่กิ๊ฟกรอกไว้แต่เครื่องไม่ได้ให้ข้อสังเกตที่เทียบเท่ากัน
🔴 นี่ยัง **ไม่ใช่คะแนน** และยังไม่ใช่ผลการประเมิน · จะเป็นการสกัดตกหล่นจริงหรือเครื่องตัดบรรทัด
ต่างจากที่คนอ่าน **เป็นคำตัดสินของกิ๊ฟ**

🔴 **ยังไม่มีเฉลยของงานวิจัยในระบบ** — ที่ทดสอบไว้เป็นข้อมูลสังเคราะห์เพื่อพิสูจน์กลไกเท่านั้น
🔴 การกรอกทะเบียนอิสระของเอกสารจริงหลายร้อยหน้าจะใช้เวลามาก — เป็นข้อจำกัดที่ต้องวางแผนล่วงหน้า
