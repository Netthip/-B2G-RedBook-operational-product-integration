## 1. สิ่งที่อยู่ในชุด

**หน้าเว็บ** `/indicators/runs/{run_id}/verify` (ในเครื่องผู้ตรวจ · loopback เท่านั้น)

| คอลัมน์ | มาจาก |
|---|---|
| สถานะที่เครื่องเสนอ + ความหมาย + เหตุผลชนิด (ไม่ใช่คะแนน) | `ind_mappings.proposed_status` · `basis` หลังถอดตัวเลข |
| ข้อความฉบับเก่า / ฉบับใหม่ **ตรงตามที่ปรากฏ** | `ind_observations.observed_text` |
| ขั้นเอกสาร / หน้า ของทั้งสองฝั่ง · ป้าย `ต้องชี้ตำแหน่ง` เมื่อไม่มีกรอบที่เชื่อถือได้ | ทะเบียนเอกสาร + `location_confidence` |
| ความต่างของ นิยาม / หน่วย / วิธีคำนวณ-ตัวหาร / รอบ / ค่าฐาน / ตัวเลข | `differences` |
| ปุ่ม `Old evidence` · `New evidence` · `เทียบข้างกัน + ตัดสิน` | route ที่ควบคุมผ่านทะเบียน (`/evidence/...`) |
| คำตัดสินล่าสุด (ถ้ามี) | `ind_decisions` |

**ไฟล์** `indpkg_<เวลา>_<id>.xlsx` (สร้างจากปุ่มบนหน้า · เก็บที่ `EXPORT_DIR` ของแอป)

* ชีต **ชุดตรวจ** — 27 คอลัมน์: `mapping_id · indicator_id (ชั่วคราว) · สถานะที่เสนอ · ความหมาย · ต้องให้คนยืนยัน · เหตุผลชนิด · ข้อความเก่า · ข้อความใหม่ · ขั้น/ปี/หน้า/ตำแหน่ง/แฮช ของทั้งสองฝั่ง · ความต่าง · ลิงก์เปิดหลักฐานเก่า/ใหม่/เทียบ (route ในระบบ) · ช่องคำตัดสิน · สถานะที่ถูกต้อง · หมายเหตุ · ผู้ตรวจ · เวลา`
* ชีต **วิธีใช้** — ขั้นตอน 5 ข้อ + ตาราง 8 สถานะ
* ชีต **สรุป** — จำนวนคู่ต่อสถานะที่เสนอ · รอคนยืนยัน · ตัดสินแล้ว · บัญชีปิดหรือไม่
* `_snapshot.json` — `run_id · document_id/sha256 ทั้งสองฝั่ง · mapping_version · rules_hash · extractor_version · "scores_included": false`

การป้องกันในไฟล์: กันสูตร (`csv_safe.neutralize`) · `privacy.assert_shareable` · ข้อความจากเอกสาร `INTERNAL_NOT_PUBLISHED`/`UNKNOWN` ถูกแทนด้วยตัวยึด `[ข้อความจากเอกสารที่ยังไม่เผยแพร่ — เปิดดูได้ในระบบเท่านั้น]` · ไม่มี `internal_score`/`trigram_dice`/ลิงก์ไฟล์ในเครื่อง (ตรวจก่อนเขียน ถ้าพบ = ไม่เขียนไฟล์)

## 2. วิธีตรวจ (สำหรับกิ๊ฟ)

1. เปิดหน้า `verify` → กดกรองสถานะที่ต้องให้คนยืนยันก่อน (`AMBIGUOUS_REVIEW_REQUIRED` · `DEFINITION_CHANGED` · `SAME_CONCEPT_REPHRASED`)
2. กด **เทียบข้างกัน + ตัดสิน** → เห็นหน้าเก่า/ใหม่พร้อมกรอบเน้น · ข้อความตามที่ปรากฏ · ความต่างนิยาม/หน่วย/วิธี
3. ถ้ากรอบไม่ตรง หรือหน้าไม่มีชั้นข้อความ (`LOCATION_REVIEW_REQUIRED`) → ใช้ปุ่ม **เปิด PDF หน้า n** แล้วชี้ตำแหน่งเอง
4. กรอก **ยอมรับ / ไม่ยอมรับ (ระบุสถานะที่ถูกต้อง) / ยังตัดสินไม่ได้** + เหตุผล + ชื่อผู้ตรวจ → บันทึก (เพิ่มอย่างเดียว · แก้ไม่ได้ · ผูก Audit Trail)
5. `RELATED_NOT_EQUIVALENT` มีให้เลือกในฟอร์มเสมอ แม้เครื่องไม่เคยเสนอ
6. เมื่อครบ กด **สร้างชุดตรวจ XLSX** เป็นบันทึกสรุป (ไฟล์คือสำเนา ไม่ใช่แหล่งจริง — แหล่งจริงคือ `ind_decisions`)
