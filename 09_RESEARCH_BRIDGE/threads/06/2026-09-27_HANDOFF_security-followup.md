คำสั่งที่รันจริง (Git Bash · `AV` = `%LOCALAPPDATA%\Temp\av`)

```bash

.venv/Scripts/python -m pip list --format=freeze > "$AV/frozen.txt"
"$AV/Scripts/python" -m pip_audit -r "$AV/frozen.txt" -f json -o "$AV/audit.json" --progress-spinner off
```
