## 1. แผนผังเว็บ (sitemap)

```
หน้าแรก /                         ← ค้นหาเล่ม · ทำงานต่อ · ทางเข้าสามทาง · งานตรวจทั้งหมด
├── คลังเล่มงบประมาณ /books        ← ค้น · กรองปี/ประเภท/หน่วยรับงบ · จัดเรียง · การ์ด/ตามเล่ม/รายการ
│   └── รายละเอียดเล่ม /books/{id} ← ข้อมูลเล่ม · หน่วยรับงบในเล่ม · เล่มเดียวกันในปีอื่น · PDF ทางการ ↗
├── เริ่มตรวจจากเล่ม /verify/start ← ช่อง A/B · คู่ที่แนะนำ · ตั้งงาน = ขั้น 1
│
└── (workflow เดิมจาก #7 — ไม่เปลี่ยนเส้นทาง)
    งานตรวจ /projects/{id}        ← ขั้น 2 ใส่ไฟล์ (+ เล่มอ้างอิง)
    รอบตรวจ /t1b/runs/{id}        ← ขั้น 3 สรุปความต่าง
    คิว /…/queue → รายการ /…/findings/{id}  ← ขั้น 4 หลักฐาน + คำตัดสิน
    Preflight /…/preflight        ← ขั้น 5 ด่านก่อนส่งออก
    ส่งออก /…/export · Audit       ← ขั้น 6
```

**หลักที่ตรึงไว้:** "เริ่มตรวจจากเล่ม" เรียกการตั้งงานตรวจ**ตัวเดิม**แล้วส่งเข้าขั้น 2 ของ workflow เดิม
— ไม่มีเส้นทางตรวจคู่ขนาน · ไม่แตะเครื่องยนต์ · โหมดงานใช้สองโหมดที่มีอยู่แล้ว
(ปีต่างกัน = "ปีก่อนเทียบปีปัจจุบัน" · ปีเดียวกัน = "ก่อนเทียบหลังปรับลด")

## 2. เส้นทางผู้ใช้ (user flow)

| Journey | เส้นทาง | จำนวนคลิกจากหน้าแรก* |
|---|---|---|
| A หาเล่ม | หน้าแรก → พิมพ์ "สาธารณสุข" → กรองปี → การ์ด → รายละเอียด → PDF ↗ | 4 (หรือ 2 ถ้าเปิด PDF จากการ์ดเลย) |
| B เอาไปตรวจ | รายละเอียดเล่ม → ตั้งงานตรวจโดยอ้างอิงเล่มนี้ → คู่ที่แนะนำ → ตั้งงานตรวจ | 3 (หรือ 1 จากการ์ด "ตามเล่ม") |
| C ตรวจงาน | ขั้น 2 ใส่ไฟล์ → หาความต่าง → คิว → รายการ+หลักฐาน → ตัดสิน → Preflight → ส่งออก | ตาม workflow เดิม |

\* นับจากการเดินอัตโนมัติ ไม่ใช่ผลวัดกับผู้ใช้ — ห้ามอ้างเป็นผลการประเมิน

ทางลัดที่ออกแบบเพื่อลดขั้น:
- การ์ดมีปุ่ม **เปิด PDF** ตรง — ไม่ต้องผ่านหน้ารายละเอียดถ้ารู้แล้วว่าใช่เล่มนี้
- หน้ารายละเอียดมี **"เทียบกับปี …"** — จับคู่เล่มเดียวกันข้ามปีในคลิกเดียว
- มุมมอง **"ตามเล่ม (เทียบปี)"** — หนึ่งการ์ดต่อเล่ม หนึ่งแถวต่อปี + ปุ่ม "เทียบ 2569 กับ 2570"
- หน้าเริ่มตรวจ **จัดฝั่งให้เอง** (ปีเก่า = A) และตั้งชื่องานให้เอง (แก้ได้)

## 4. การ์ดเล่ม — อ่านอย่างไร

```
┌──────────────────────────────┐
│▌ เล่ม 3(2)            [2570] │  ← ปกจำลอง: เล่ม + ฉบับ + ปี (สแกนด้วยตา)
│▌ ฉบับที่ 3                    │
├──────────────────────────────┤
│ กระทรวงการอุดมศึกษา            │  ← ชื่อหน่วยรับงบ (สิ่งที่ผู้ใช้ตามหา)
│ วิทยาศาสตร์ วิจัยและนวัตกรรม    │     หลายหน่วย → "ก · ข และอีก N หน่วย"
│ [รายจ่ายรายกระทรวง]           │  ← ประเภท
│ ✓ ลิงก์ทางการ · สำนักงบประมาณ   │  ← แหล่ง + สถานะลิงก์
├──────────────────────────────┤
│ [ตั้งงานตรวจโดยอ้างอิงเล่มนี้]  │  ← ทางไปต่อหลัก (D3)
│ [เปิด PDF ต้นทาง ↗]           │
└──────────────────────────────┘
```

ร่างแรกมีปี 2 ที่ (ปก + ป้าย) และ "ฉบับที่ 3" 3 ที่ — ตัดออกหลังทบทวนภาพหน้าจอ
เหลือข้อมูลละหนึ่งที่ · ชื่อเต็มอ่านได้จาก tooltip และหน้ารายละเอียด ·
ผู้ใช้โปรแกรมอ่านหน้าจอได้ยิน "เอกสารงบประมาณ ฉบับที่ 3 · เล่มที่ 3(2) ปีงบประมาณ 2570 — …" ครบ

### การ์ด "ตามเล่ม (เทียบปี)" — ค่าเริ่มต้น (D1)

หนึ่งการ์ด = หนึ่งเล่ม (ชุดหน่วยรับงบเดียวกัน) · หนึ่งแถว = หนึ่งปี พร้อมปุ่ม PDF ของปีนั้น
· ปุ่มหลัก "ตั้งงานตรวจ: ปี 2569 เทียบ 2570" — ผลค้น "สาธารณสุข" จึงเหลือการ์ดเดียวที่มีครบสามปี
แทนการ์ดหน้าตาเหมือนกันสามใบ · มุมมองรายเล่มและรายการยังเลือกได้

### แถบที่มาของข้อมูล (D4)

ในโหมดสาธิต ทุกหน้ามีแถบ: **เล่มอ้างอิง = เอกสารสาธารณะจากสำนักงบประมาณ** ·
**สมุดงานที่ใช้สาธิตการตรวจ = ข้อมูลสังเคราะห์ ไม่ได้มาจาก PDF ของเล่ม** — ปรากฏในภาพหน้าจอทุกภาพด้วย
นอกโหมดสาธิต เล่มอ้างอิงมีป้าย "เอกสารสาธารณะ" ในหน้าตั้งงานตรวจและหน้างานตรวจ

## 5. สถานะของหน้าจอ

| สถานะ | ที่ใดบ้าง | สิ่งที่ผู้ใช้เห็น |
|---|---|---|
| ว่าง (ไม่พบผล) | คลังเล่ม | บอกว่าไม่พบ + ทางแก้ (ตัดคำค้น/เลือกทุกปี) + ปีที่มีในคลัง + ปุ่มล้างตัวกรอง |
| ว่าง (ยังไม่มีงาน) | หน้าแรก | ข้อความเดิมของ #7 + ทางเข้าหาเล่ม |
| ผิดพลาด — ไม่พบเล่ม | `/books/{id}` | หน้าแจ้งข้อผิดพลาดกลางของระบบ (404 · ไม่มี stack trace · มีรหัสอ้างอิง) |
| ผิดพลาด — เลือกเล่มไม่ถูก | เริ่มตรวจ | กล่องแดง: เล่มซ้ำทั้งสองฝั่ง / รหัสไม่อยู่ในคลัง (400) |
| เตือน — คู่ไม่ใช่เล่มเดียวกัน | เริ่มตรวจ | กล่องเหลือง: ตรวจได้แต่ความต่างอาจมาจากการเลือกเล่มคนละชุด |
| ลิงก์ทางการเปิดไม่ได้ | การ์ด/รายละเอียด | ข้อความสีเหลือง + ให้ใช้หน้าเผยแพร่ทางการแทน (ทุกเล่มเปิดได้ ณ วันตรวจ) |
| กำลังโหลด/ประมวลผล | ทุกหน้า | หน้าเว็บเรนเดอร์ฝั่งเซิร์ฟเวอร์ — ค้น/กรองตอบทันทีจากทะเบียนในหน่วยความจำ · ขั้นหาความต่างใช้หน้าจอของ #7 เดิม |

## 6. รองรับจอแคบ

- ≤ 1100px: ตัวกรองย้ายขึ้นเหนือผลลัพธ์เป็นแนวนอน
- ≤ 980px: เมนูซ้ายเป็นแถบเลื่อนแนวนอนด้านบน · หน้ารายละเอียดเล่มเรียงแนวตั้ง · ช่อง A/B ซ้อนกัน
- ≤ 560px: ช่องค้นหาและปุ่มซ้อนกัน · การ์ดหนึ่งคอลัมน์
- ตรวจด้วยเบราว์เซอร์จริงที่ 390px: **ไม่มีแถบเลื่อนแนวนอน**
- เป้าหลักยังเป็นจอคอมพิวเตอร์ในสำนักงาน — จอแคบ "ใช้ได้" ไม่ใช่ "ออกแบบมาเพื่อ"

## 7. ทะเบียนเล่ม (data)

- สร้างซ้ำได้ด้วยสคริปต์เดียวใน repo โค้ด · พบและแก้ระหว่างสร้าง: เลขไทยในชื่อเล่มหลุดเข้าวันที่ · ชื่อหน่วยงานที่หน้าทางการสะกดสองแบบ
