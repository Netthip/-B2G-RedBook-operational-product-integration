| S-5 | เอกสารการเก็บ/ลบข้อมูล และ data-flow แบบ local-only | `READY` | เป็นเอกสารล้วน |

🔴 **ZAP อย่างเดียวไม่เคยเป็นหลักฐานความปลอดภัยที่สมบูรณ์** (คำสั่ง Bo ย้ำสองรอบ)

### ความเสี่ยงที่พบแล้วและยังเปิดอยู่

1. **`RUN_MANIFEST.json` บันทึก path สัมบูรณ์ของเครื่องผู้ใช้** — ไฟล์อยู่นอก git
   จึงยังไม่รั่ว แต่ **ต้องปกปิดก่อนแนบเป็นภาคผนวก**
2. **formula injection** — repo **ไม่มีการส่งออก CSV** จึงยังไม่เสี่ยงในโค้ดที่ commit
   แต่สคริปต์รัน shadow run นอก repo เขียน CSV โดยไม่ escape และค่า `raw_value`
   มี `#VALUE!` และข้อความจากเซลล์จริง 🔴 **ต้องปิดก่อน `O-P10`**
3. **ไม่มีระบบผู้ใช้เลย** — ต้องประกาศเป็นข้อจำกัดของบริบทการติดตั้ง ไม่ใช่ปล่อยผ่าน
