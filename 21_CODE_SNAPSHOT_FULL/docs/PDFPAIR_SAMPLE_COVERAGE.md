## 3. ข้อเสนอรอบสุ่มถัดไป (ยังไม่ทำ · รอโบ/กิ๊ฟ)

สุ่มแบ่งชั้นตาม **ชนิด × ตาราง/หัวข้อ/ระดับ** (ทุกชั้นในตารางข้อ 2 อย่างน้อย 1) + เพิ่มยอดรายการ · บรรทัดรายการผูกพัน ·
หลักฐานขั้นเอกสาร เข้ากรอบการสุ่ม — ทำหลังรุ่นนี้ผ่านการตรวจ เพื่อไม่ให้ตัวอย่างใหม่ปนกับการแก้ที่ยังไม่ตรึง
