## 2. วิธีตรวจทีละรายการ (7 ขั้น)

คำแนะนำเดียวกันนี้อยู่ในชีต **"วิธีตรวจ"** ซึ่งเป็นชีตแรกของไฟล์ xlsx —
เปิดไฟล์เดียวเห็นครบ ไม่ต้องอ่าน JSON และไม่ต้องค้นตำแหน่งเซลล์เอง
(คอลัมน์ "ตำแหน่งหลักฐาน A/B" บอกไฟล์และเซลล์ที่ต้องเปิดให้แล้ว เช่น `…xlsx!M4972`)

สำหรับแต่ละแถวในชีต "Review":

1. **เปิดหลักฐานฝั่ง A** ตามคอลัมน์ "ตำแหน่งหลักฐาน A"
2. **ตรวจค่าฝั่ง A** ว่าตรงกับ "ค่าดิบฝั่ง A" หรือไม่ แล้วเลือก "เปิดแล้ว" ในช่อง "เปิดหลักฐาน A แล้ว"
3. **เปิดหลักฐานฝั่ง B** ตามคอลัมน์ "ตำแหน่งหลักฐาน B"
4. **ตรวจค่าฝั่ง B** ว่าตรงกับ "ค่าดิบฝั่ง B" หรือไม่ แล้วเลือก "เปิดแล้ว" ในช่อง "เปิดหลักฐาน B แล้ว"
5. **ตรวจหมวด C1–C7 ที่ระบบให้** ว่าสอดคล้องกับหลักฐานหรือไม่ — ในรุ่น 1.2.0
   หมวดนี้แสดงเป็น "ทิศทางการเปลี่ยนแปลง" (▼ ▲ ＝ ?) ในชีต Review และแสดงรหัสหมวดเต็ม
   ในชีต Technical Details คอลัมน์ "หมวดผลตรวจ"
6. **เลือกคำตอบ** ในช่อง "คำตอบผู้วิจัย" (มี dropdown):

   | คำตอบ | ความหมาย |
   |---|---|
   | **ยืนยัน** | ค่าฝั่ง A และ B ตรงกับหลักฐาน และหมวดที่ระบบให้สอดคล้องกับค่าที่เห็น |
   | **ไม่ยืนยัน** | ค่าไม่ตรงกับหลักฐาน หรือหมวดไม่สอดคล้องกับหลักฐาน |
   | **ไม่แน่ใจ** | เปิดหลักฐานแล้วยังสรุปไม่ได้ |

7. **เขียนเหตุผลสั้น ๆ เฉพาะรายการที่เลือก "ไม่ยืนยัน" หรือ "ไม่แน่ใจ"**
   แล้วกรอก "วันเวลาที่ตรวจ" (เช่น `28/08/2569 14:30`)

ช่อง "ความมั่นใจผู้วิจัย" (สูง/ปานกลาง/ต่ำ) กรอกประกอบได้ ไม่บังคับต่อการปิดรายการ

ไฟล์หลักฐานอยู่ที่ `.data\public_sources\fy2569\` (ชุด supplementary มีรายการ Y2 ที่ใช้
`fy2570\` ด้วย) — **เปิดแบบอ่านอย่างเดียว ห้ามแก้ไขหรือบันทึกทับ**
· รุ่น 1.2.0 กดที่ข้อความในคอลัมน์ "ตำแหน่งหลักฐาน" เพื่อเปิดไฟล์ที่เซลล์นั้นได้ทันที
หรือดูบริบทรอบข้างในชีต **Evidence Preview** โดยไม่ต้องเปิดไฟล์ต้นทาง

> **กด Ctrl+S ทุกครั้งที่กรอกเสร็จ 2–3 รายการ** — Excel ไม่บันทึกให้เองตอนปิดไฟล์
> หากปิดโดยไม่บันทึก คำตอบที่กรอกไว้จะหายทั้งหมด

## 4. สิ่งที่ผลการตรวจนี้ใช้อ้างได้และอ้างไม่ได้

**เรียกผลชุดนี้ว่า**

> ผลการตรวจสอบตัวอย่าง findings เพื่อประเมินความสอดคล้องของผลระบบกับหลักฐาน

**อ้างได้** — ความสอดคล้องระหว่างผลที่ระบบรายงานกับหลักฐานในเอกสาร ในตัวอย่างที่ตรวจ

**อ้างไม่ได้**

- ❌ ค่าความแม่นยำของ finding ทั้งหมด (26,410 รายการ)
- ❌ ความแม่นยำของประชากรทั้งกระทรวง
- ❌ นำผล Primary กับ Supplementary มารวมเป็นตัวเลขเดียว
- ❌ ใช้แทนตัวชี้วัด Precision / Recall / F1 ซึ่งมาจาก M-SET เท่านั้น

ต้องรายงาน**ข้อจำกัดด้านขนาดตัวอย่าง**กำกับทุกครั้ง
