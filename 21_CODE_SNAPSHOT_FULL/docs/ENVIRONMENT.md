# สถานะสภาพแวดล้อมของระบบ (Environment Status)

ปรับปรุงล่าสุด: 27 สิงหาคม 2569 · ตามข้อกำหนดของผู้รับผิดชอบงานวิจัย (26 ส.ค. 2569)

## สถานะปัจจุบัน

ระบบที่รันอยู่ที่ `http://127.0.0.1:8600` มีสถานะเป็น

> **สภาพแวดล้อมพัฒนาและทดสอบภายในเครื่อง (local development/test environment)**

เท่านั้น — **ห้าม**เรียกว่า "ระบบบนคลาวด์ส่วนตัว" หรือ "production system"
เพราะยังไม่ได้ติดตั้งและตรวจสอบบนสภาพแวดล้อมดังกล่าว

## เป้าหมายการติดตั้งภายหลัง (ยังไม่ได้ทำ)

โครงการวิจัยกำหนดเป้าหมายการติดตั้งในอนาคตไว้สองสภาพแวดล้อม:

| สภาพแวดล้อม | ใช้ทำอะไร | สถานะ |
|---|---|---|
| `test` environment | การทดลองและการสแกน OWASP ZAP (baseline + active scan) | **ยังไม่ได้ติดตั้ง** |
| `private production/demo` environment | การสาธิตระบบ | **ยังไม่ได้ติดตั้ง** |

การติดตั้งบนคลาวด์**ไม่ใช่**สิ่งที่ Phase 1 ทำเสร็จแล้ว และจะไม่ถูกอ้างว่าเสร็จ
จนกว่าจะติดตั้งจริง ตรวจสอบจริง และมีหลักฐานประกอบ

## กติกาการใช้ถ้อยคำในเอกสารและหน้าจอ

- หน้าจอและเอกสารทุกฉบับของโครงการนี้ เมื่อกล่าวถึงระบบที่รันอยู่ ให้ใช้คำว่า
  "สภาพแวดล้อมพัฒนาและทดสอบภายในเครื่อง" หรือ "local development/test environment"
- คำว่า "ติดตั้งใช้งานจริง" หรือ "production" ใช้ได้เฉพาะเมื่อการติดตั้งนั้นเกิดขึ้นจริง
  และมีหลักฐานการตรวจสอบประกอบ
