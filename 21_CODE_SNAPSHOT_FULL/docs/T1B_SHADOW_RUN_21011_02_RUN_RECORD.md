**ข้อจำกัดใหม่ที่รอบนี้สร้างขึ้นเอง**

* `agency_identity` อ่านจาก **ชีตปก** — ถ้าชีตปกอ่านไม่ได้ ด่านจะรายงาน
  `agency_identity_not_readable_from_content` ซึ่ง **ไม่ได้หยุดการจับคู่**
  จึงยังต้องมีคนอ่านสถานะนี้ทุกครั้ง 🔴 **`ยืนยันไม่ได้` ไม่เท่ากับ `ผ่าน`**

  คีย์จะไม่ตรงและทุกรายการจะกลายเป็น `ROW_ADDED`/`ROW_REMOVED`
  (ดังขึ้นชัด ไม่เงียบ แต่ยังเป็นข้อจำกัดที่ต้องบอก)
* ปีบริบทของตารางแกนหมวดที่มาจาก `workbook_cover` เป็น **ปีของเอกสาร**
  ไม่ใช่ปีที่พิสูจน์ได้จากตัวตารางเอง — บันทึกที่มาไว้ในฟิลด์
