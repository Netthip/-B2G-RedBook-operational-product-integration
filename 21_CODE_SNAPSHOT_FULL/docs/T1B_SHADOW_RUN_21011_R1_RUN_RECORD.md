### ข้อ 6 — เข้าเงื่อนไข

record ที่มี `comparison_axis = BUDGET_CATEGORY` ถูกบังคับให้ `fiscal_year = None`
ตาม truth table ของ `axis_valid` แต่ตารางจำแนกหมวดงบรายจ่ายในแฟ้มจริง **ผูกกับปีของแฟ้ม**
(หัวเรื่องชีตบทบาท `SECTION_06` ระบุปีงบประมาณไว้ชัดเจน และเป็นคนละปีในสองแฟ้ม)

ผลคือ **34 คู่จาก 236 คู่ที่จับคู่ได้ (14.4%)** เป็นการเทียบยอด **ปีหนึ่งกับอีกปีหนึ่ง**
โดยช่อง `fiscal_year` ว่าง และปนอยู่ในไฟล์เดียวกับ finding ที่เทียบปีเดียวกัน
ในนั้น **12 คู่ออกเป็น `AMOUNT_INCREASED` / `AMOUNT_DECREASED`**

ตัวเลขทุกตัว **ถูกต้องตามเซลล์** ปัญหาอยู่ที่ finding ไม่ได้บอกว่าเป็นการเทียบข้ามปี

**การดำเนินการ: บันทึกเป็น observation · ไม่แก้ในรอบนี้** ตามคำสั่งข้อ 4 ของรอบ
รอคำตัดสินของ Gift และ Bo
