# ภาพนิ่งโค้ดเต็ม — RedBook Verify (หลังบ้าน)

ภาพนิ่งของต้นไม้โค้ดทั้งหมด ณ รุ่น `287a2fe` (branch `be/42-backend`) สำหรับบันทึกขั้นตอนงานค้นคว้าอิสระ ให้ผู้อ่าน (คนหรือ AI) อ่านวิธีทำงานได้
ไม่ใช่รีโปพัฒนาต่อ และไม่มีประวัติ commit เดิม (ส่งออกด้วย `git archive`)

- ต่างจาก `20_CODE_SNAPSHOT_PDF_LANE/`: ชุดนี้รวมทุกส่วน — สาย Excel/T1B · reviewpack · security_gate · scripts · docs บันทึกการทดลอง
- กิ๊ฟอนุมัติให้ขึ้นเต็ม 2 พ.ย. 2569
- ก่อนขึ้นสแกนแล้ว: ไม่พบชื่อหน่วยงานชุดประเมิน · อีเมล · โทเค็น/กุญแจ · ที่อยู่ไฟล์ในเทสต์เป็นตัวอย่างปลอม (`C:\Users\someone\...`)
- ไม่รวม: ไฟล์ PDF/Excel จริง · ฐานข้อมูลเดโม · รูปบุคคล · สมุด `/r/book` (อยู่ branch อื่น)
- ไฟล์ทั้งหมดพร้อมค่า SHA-256 อยู่ใน `MANIFEST.sha256`

ทดสอบ (Python 3.12 · ติดตั้งจาก `requirements.lock.txt` + pytest httpx pymupdf):

    python -m pytest -q tests
