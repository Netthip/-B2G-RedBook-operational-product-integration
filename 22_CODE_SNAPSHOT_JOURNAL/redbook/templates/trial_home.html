ขั้นตอน (บอกตามจริง)

  1. เลือกเล่ม — ใช้งานจริงต้องอัปโหลดไฟล์ PDF สองฉบับเอง (ฉบับปัจจุบัน + ฉบับที่เทียบ) · รอบทดลองนี้เตรียมเล่มไว้ให้แล้ว จะได้ไม่ต้องหาไฟล์
  2. อ่านคำชี้แจง — ปีปัจจุบันต้องถูกต้องเป็นหลัก · ช่วยดูตัวชี้วัด วิสัยทัศน์ พันธกิจ ว่าอะไรหายไป เพิ่มเข้ามา หรือไม่ใช้แล้ว
  3. วงจุดบนภาพหน้า เหมือนตรวจบนกระดาษ — ปากกาแดง = สำคัญ · ปากกาน้ำตาล = สังเกตเห็นแต่สำคัญน้อยกว่า · หมุด = ของที่หายไป · เปิดฉบับก่อนวางข้างกันได้ · กด "ตรวจหน้านี้แล้ว" ทีละหน้า
  4. ส่งผลตรวจ — ล็อกจุดที่วง แก้ไม่ได้อีก · ระบบยังไม่เทียบจนกว่าคุณจะส่ง จะได้ไม่เห็นคำตอบของระบบก่อน
  5. ดูว่าระบบเจออะไร — ระบบเสนอว่าจุดที่คุณวงตรงกับข้อไหนของระบบ คุณกดยืนยันทีละข้อ แล้วจัดข้อที่ระบบยกเพิ่ม
  6. แบบสอบถามหน้าเดียว — คลิกเลือก แล้วบันทึกลงเครื่อง
  7. ดูแดชบอร์ด และดาวน์โหลดสรุปเฉพาะจำนวน ส่งให้ผู้วิจัย (ไม่มีตำแหน่งหรือหมายเหตุของจุดที่วง)
