# บันทึกการตรวจแหล่งเผยแพร่สาธารณะ (สำนักงบประมาณ)

ตรวจเมื่อ: 27 สิงหาคม 2569 · วิธีตรวจ: เปิดอ่านหน้าเว็บโดยตรง (ไม่ได้ดาวน์โหลดไฟล์ใด)

> **เหตุที่ต้องมีบันทึกนี้:** สถานะ "สาธารณะ" ของข้อมูลต้องมีหลักฐานที่ตรวจย้อนได้
> ไม่ใช้การบอกต่อเป็นฐาน — บันทึกนี้แยก **สิ่งที่เห็นจริง** ออกจาก **สิ่งที่ยังไม่ได้ตรวจ**

## 1. สิ่งที่ตรวจแล้วและเห็นจริง

**URL ที่ตรวจ:**
- `https://www.bb.go.th/topic-detail.php?id=18879&mid=544&catID=0`
- `https://www.bb.go.th/topic3.php?catID=1511&gid=860&mid=544` (ชุดปีงบประมาณ 2569)

**สิ่งที่ปรากฏบนหน้า:**

| ประเด็น | สิ่งที่เห็น |
|---|---|
| หมวด | เอกสารงบประมาณ → เอกสารงบประมาณอิเล็กทรอนิกส์ |
| ชุดเอกสาร | **ฉบับร่างพระราชบัญญัติงบประมาณรายจ่าย (ร่าง พ.ร.บ.)** และ **ฉบับพระราชบัญญัติงบประมาณรายจ่าย (พ.ร.บ.)** |
| ปีที่เผยแพร่ | 2560–2570 (รวม ร่าง พ.ร.บ. โอนงบประมาณ 2569 และฉบับเพิ่มเติม 2567, 2560) |
| ชนิดไฟล์ | **PDF** สำหรับฉบับร่างและฉบับ พ.ร.บ. · **Excel** สำหรับ "ข้อมูลแบบ Excel Data Table" (จำแนกรายจ่ายประจำและลงทุน) |
| การจัดหมวด | จัดตามปีงบประมาณ — **หน้าดัชนีไม่ได้แยกตามกระทรวงหรือหน่วยงาน** |
| ข้อความสงวนสิทธิ์ | **ไม่พบ**ข้อความสงวนสิทธิ์หรือเงื่อนไขการนำไปใช้บนหน้าที่ตรวจ |
| คำว่า "ขาวคาดแดง" / "ฉบับปรับลด" | **ไม่พบ**บนหน้าที่ตรวจ (ชื่อทางการที่ใช้คือ "ร่าง พ.ร.บ." และ "พ.ร.บ.") |

## 2. ข้อสังเกตที่มีนัยต่องานวิจัย

การที่เว็บเผยแพร่ทั้ง **ร่าง พ.ร.บ.** และ **พ.ร.บ.** ของปีเดียวกัน หมายความว่า
มีเอกสารสองฉบับที่ต่างกันด้วยกระบวนการพิจารณาของรัฐสภาให้เทียบกันได้จากแหล่งสาธารณะ
— **อาจ**ใช้เป็นคู่ "ก่อน–หลังการปรับลด" ที่เผยแพร่ได้ แทนการใช้เอกสารภายใน

⚠ **ยังสรุปไม่ได้** จนกว่าจะตรวจเพิ่ม (ดูข้อ 3) ว่าความต่างระหว่างสองฉบับนี้
ตรงกับนิยาม "ปรับลด" ที่งานวิจัยใช้หรือไม่ และมีรายละเอียดถึงระดับรายการของหน่วยงานหรือไม่

## 3. สิ่งที่ยังไม่ได้ตรวจ (ห้ามอ้างจนกว่าจะตรวจ)

1. เนื้อในเอกสารแต่ละเล่ม — ยังไม่เปิดดู จึงยังไม่ทราบว่ามีรายละเอียดถึงระดับ
   หน่วยรับงบประมาณและรายการหรือไม่
2. ขอบเขตของ "Excel Data Table" ว่าครอบคลุมระดับรายการของแต่ละหน่วยงานหรือเป็นยอดรวม
3. เงื่อนไขการนำไปใช้ / ลิขสิทธิ์ / การอ้างอิง ที่อาจอยู่ในหน้าอื่นของเว็บไซต์
4. ความสัมพันธ์ระหว่างเอกสารสาธารณะเหล่านี้กับไฟล์ Excel ภายในที่ใช้ใน Phase 2A
   (คนละแบบฟอร์ม คนละหน่วยเงิน — ต้องพิสูจน์ว่าเทียบกันได้จริงก่อนใช้ร่วมกัน)

## 4. สิ่งที่ยังไม่ได้ทำและจะไม่ทำเองโดยพลการ

- **ยังไม่ได้ดาวน์โหลดไฟล์ใดจากเว็บไซต์** — การดาวน์โหลดจะทำเมื่อผู้รับผิดชอบงานวิจัย
  สั่งอย่างชัดแจ้ง พร้อมระบุว่าจะเก็บที่ใด
- ไม่นำเอกสารสาธารณะมาปนกับชุดไฟล์ภายในในงานตรวจเดียวกัน จนกว่าจะยืนยัน mapping
  ของทั้งสองแบบฟอร์มแยกกันก่อน

## 5. ผลต่อการวางแผนระยะถัดไป

| ถ้าใช้แหล่งสาธารณะ | ผลกระทบ |
|---|---|
| เอกสารเป็น **PDF** เป็นหลัก | ตกอยู่ในขอบเขต **Phase 3 (PDF comparator)** ไม่ใช่ Phase 2 — และเครื่องนี้ยังไม่มีไลบรารี PDF/OCR |
| "Excel Data Table" | อาจใช้กับ Phase 2 ได้ ถ้าลงลึกถึงระดับรายการ — ต้องตรวจก่อน |
| ข้อดี | หลักฐานในเล่ม IS เผยแพร่ได้ ลดข้อจำกัดเรื่องการเปิดเผยข้อมูล |
| ข้อควรระวัง | เป็น**คนละชุดข้อมูล**กับไฟล์ภายใน — ห้ามนำผลตรวจของสองชุดมาปนกันโดยไม่ระบุที่มา |
