## G2 — Semantic Mapping จาก Data Dict (freeze)

**สิ่งที่ขออนุมัติ:** วิธี map ชื่อคอลัมน์กายภาพไปยัง canonical field โดย**ไม่ผูกกับชื่อคอลัมน์โดยตรง**

**ขั้นตอนที่เสนอ:**
1. อ่านชีต `Data Dict` → ได้คู่ (ลำดับ, ชื่อฟิลด์, นิยาม)
2. อ่านแถวหัวของชีต `data` → ได้ชื่อคอลัมน์กายภาพตามลำดับ
3. จับคู่**ตามลำดับ** และตรวจสอบชื่อ — ถ้าชื่อไม่ตรงให้บันทึกเป็น `physical_name_drift`
   (ไม่ใช่ข้อผิดพลาด) พร้อมหลักฐาน
4. map ฟิลด์จาก Data Dict → canonical field ตามตารางใน G1
5. ถ้านิยามใน Data Dict ของสองไฟล์ที่จะเทียบกัน**ไม่ตรงกัน** → **หยุดเป็น `schema_conflict`**

**สิ่งที่บันทึกต่อการ map หนึ่งคอลัมน์:** source column · canonical field ·

## G4 — หมวดผลตรวจและกฎการจัดหมวด (freeze)

**หมวดผลตามที่อนุมัติใน D3 — ห้ามเรียกรวมทุก finding ว่า "รายการปรับลด"**

| รหัส | หมวด | เงื่อนไข | machine status |
|---|---|---|---|
| C1 | **วงเงินลดลง** | จับคู่ได้ และ `amount(B) < amount(A)` | `diff_found` |
| C2 | **วงเงินเพิ่มขึ้น** | จับคู่ได้ และ `amount(B) > amount(A)` | `diff_found` |
| C3 | **วงเงินไม่เปลี่ยนแปลง** | จับคู่ได้ และ `amount(B) == amount(A)` | `match` |
| C4 | **รายการเพิ่ม** | มีคีย์ในฝั่ง B ไม่มีในฝั่ง A | `needs_human` |
| C5 | **รายการหาย** | มีคีย์ในฝั่ง A ไม่มีในฝั่ง B | `needs_human` |
| C6 | **โครงสร้างเปลี่ยน** | `item_label` เดิมแต่ parent path ต่าง → `possible_structure_move` | `needs_human` |
| C7 | **ยังตีความไม่ได้** | `ambiguous` · `schema_conflict` · `unit_unconfirmed` · อ่านค่าไม่ได้ | `needs_human` |

**ข้อบังคับด้านถ้อยคำ:** C1 เรียกได้เพียง "วงเงินลดลง" ในเชิงผลต่างทางตัวเลข ·
**ห้ามสรุปสาเหตุของการลดเกินกว่าเอกสารอ้างอิง** · ห้ามใช้คำว่า "ปรับลด" กับ C2–C7

**tolerance (ตาม D9):** T1 = **0 บาท (exact)** · ผลต่าง 1 บาทก็ต้องปรากฏเป็น finding · **ห้ามซ่อน**

**หมวด `possible_structure_move` (ตาม D10):** แยกออกจากยอดสรุปที่ยืนยันแล้ว ·
หลัง Human Review → `confirmed move` = 1 finding · `rejected move` = รายการหาย + รายการใหม่ ·
`unresolved` = คงแยกจากยอดสรุป

สาระสำคัญ:
1. แบ่งชุดข้อมูลเป็น 4 กลุ่ม (D-SET · E-SET · C-SET · M-SET) — ดูเอกสารแนบ

   SHA-256 ของไฟล์ทั้งสองฝั่ง · เวลาเริ่ม-จบ · จำนวน finding แต่ละหมวด
