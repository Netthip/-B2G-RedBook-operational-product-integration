## 2. สิ่งที่เก็บไว้ได้หลังการลบ

เหลือเฉพาะรายการใน `audit_log` ซึ่ง **ลบไม่ได้** ด้วย trigger ระดับฐานข้อมูล
(`audit_log_no_update` · `audit_log_no_delete`) และเก็บได้เฉพาะ

* เวลาที่ดำเนินการ
* ค่าแฮช SHA-256 ของไฟล์ — ใช้ยืนยันย้อนหลังว่าเคยตรวจไฟล์ใด โดยไม่เก็บตัวไฟล์
* รุ่นของเครื่องยนต์ที่ใช้ (`key` · `matching` · `compare` · `service`)
* สถานะการดำเนินการและจำนวนนับ

**ห้ามเก็บ** ชื่อรายการงบประมาณ · ยอดเงิน · ตำแหน่งเซลล์ · ชื่อหน่วยงานที่อ่านได้
จากเนื้อในแฟ้ม · ชื่อไฟล์ต้นฉบับ

> เหตุผลที่ต้องเข้มกับ `audit_log` เป็นพิเศษ — ตารางนี้ **ลบไม่ได้ตามการออกแบบ**
> อะไรที่เขียนลงไปจึงอยู่ถาวร การเผลอเขียนยอดเงินลงไปเพียงครั้งเดียว
> เท่ากับทำให้นโยบายข้อ 5 เป็นโมฆะโดยแก้กลับไม่ได้

## 3. สิ่งที่นโยบายนี้ **ไม่ได้** ครอบคลุม

* ไฟล์ต้นฉบับของผู้ใช้ที่อยู่นอกแอป เช่นใน OneDrive — แอป **ไม่แตะ ไม่ย้าย
  ไม่ลบ ไม่เปลี่ยนชื่อ** ไฟล์เหล่านั้นเลย
* สำเนาสำรองที่ผู้ใช้ทำเอง
* ระยะเวลาเก็บรักษาตามระเบียบราชการ — **ยังไม่ได้กำหนด** และต้องหารือก่อน
  นำไปใช้กับงานจริง
* การเก็บรักษาบนเครื่องแม่ข่ายใด ๆ — ยังไม่มีการติดตั้งแบบนั้น และถ้าจะมี
  ต้องเปิดเผยระยะเวลาเก็บรักษาและผ่านชุดทดสอบความเป็นส่วนตัวก่อน

## 4. ชุดข้อมูลที่กันไว้ (P1 holdout)

P1 อยู่นอกนโยบายนี้เพราะ **ไม่ควรเข้ามาในระบบตั้งแต่แรก** — ดู
[`redbook/holdout.py`](../redbook/holdout.py)

* ด่านบังคับในโค้ด ไม่ใช่ข้อตกลง · ไม่มีสวิตช์ปิดด้วย environment variable
* ไฟล์ P1 ที่ผู้ใช้อัปโหลดเองจะถูกปฏิเสธ **ก่อนเขียนลงดิสก์**
* P1 เปิดใช้ได้เฉพาะขั้นการประเมิน (validation) ภายหลัง
  **เมื่อกิ๊ฟอนุมัติเป็นลายลักษณ์อักษร** เท่านั้น

## 5. หลักฐานการทดสอบ

`tests/test_retention_delete.py` — 16 ข้อ ครอบคลุม

* หน้ายืนยันบอกครบว่าจะลบอะไรและจะเหลืออะไร
* ต้องพิมพ์คำยืนยันและต้องมี CSRF จึงจะลบได้
* ไฟล์หายจากดิสก์จริง ไม่ใช่หายแค่จากฐานข้อมูล
* รอบ T1A/T1B และ finding หายครบ
* audit เหลือเฉพาะ metadata · **ตรวจทั้ง Audit Trail** ว่าไม่มีเนื้อหางบประมาณหลงเหลือ
* โซ่แฮชของ audit ยังตรวจผ่านหลังลบ · และแถว audit ลบไม่ได้จริง
* ไม่มี scheduler/timer ใดในแพ็กเกจที่ลบไฟล์ผู้ใช้เอง

`tests/test_p1_holdout.py` — 20 ข้อ · พิสูจน์ว่าไฟล์ในเขตกันไว้ **ไม่ถูกเปิดอ่าน**
โดยครอบ `builtins.open` และ `zipfile.ZipFile`
