## 7. ข้อจำกัดที่ต้องระบุในเล่ม IS

1. **ระบบยังไม่เปรียบเทียบเนื้อหาเอกสาร** ระยะนี้เปรียบเทียบได้เฉพาะ metadata ที่ผู้ใช้ระบุ
   และอ่านโครงสร้างสมุดงานได้ ยังไม่เทียบค่าในเซลล์
2. **ปีงบประมาณ หน่วยงาน และประเภทเอกสารมาจากที่ผู้ใช้กรอก** ระบบไม่อ่านค่าเหล่านี้จากในเอกสารเอง
   เพราะยังไม่มี mapping ที่ผู้ใช้อนุมัติ — เป็นการตั้งใจ ไม่ใช่ข้อบกพร่อง
3. **openpyxl อ่านค่าของสูตรได้เฉพาะที่ Excel บันทึก cache ไว้** ถ้าไฟล์ไม่เคยเปิดด้วย Excel
   ระบบจะรายงานว่า "อ่านค่าไม่ได้" และ**ไม่คำนวณแทนให้** (ตัวประเมินสูตรของเราเองจะมาใน Phase 2)
4. **การนับสถิติโครงสร้างจำกัดที่ 2,000 แถวแรกต่อชีต** เพื่อไม่ให้หน้าเว็บค้างกับไฟล์ใหญ่
   หน้าจอระบุขอบเขตนี้ไว้ทุกครั้ง
5. **ไม่มีการยืนยันตัวตน** ระบบเป็นผู้ใช้เดี่ยวบน loopback
6. **ยังไม่มีรายงานผลการสแกน ZAP**
