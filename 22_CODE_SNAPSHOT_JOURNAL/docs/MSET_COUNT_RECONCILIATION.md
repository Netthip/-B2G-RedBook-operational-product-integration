## 5. นิยามศัพท์ที่ต้องไม่ปนกัน

| ศัพท์ | นิยาม |
|---|---|
| **primary mutation** | การเปลี่ยนแปลงหนึ่งรายการที่ผู้วิจัยตั้งใจใส่ลงชุดทดสอบ ตามชนิด MUT-01..MUT-09 |
| **linked impact** | ผลที่ตามมาจาก primary mutation หนึ่งรายการโดยไม่ใช่การเปลี่ยนแปลงเพิ่ม เช่น เมื่อเพิ่มแถวใหม่ในฝั่ง B แถวเดิมฝั่ง A ยังคงเป็นรายการที่ไม่เปลี่ยนแปลง |
| **negative control** | การเปลี่ยนแปลงที่คาดหวังว่าระบบจะ 'ไม่' รายงานความต่างของค่า ใช้ตรวจการรายงานเกินจริง (false positive) |
| **expected finding** | ตำแหน่งเฉลยหนึ่งตำแหน่งที่ระบุว่าระบบควรจำแนกเป็นหมวดใด หนึ่ง primary mutation อาจมีมากกว่าหนึ่ง expected finding |
| **detected finding** | รายการผลตรวจที่ระบบสร้างจริงหนึ่งรายการ |
| **unique atomic finding** | หนึ่ง detected finding ที่ผูกกับตำแหน่งเซลล์เฉพาะเจาะจงหนึ่งจุด ไม่ซ้ำกับรายการอื่น |
| **source location** | ตำแหน่งเซลล์ต้นทาง (ไฟล์ · ชีต · แถว · คอลัมน์) ที่ finding อ้างถึง |
| **automated test case** | กรณีทดสอบใน pytest ซึ่งเป็นคนละมิติกับตำแหน่งเฉลยของ M-SET ห้ามนำจำนวนมารวมหรือแทนกัน |
