จึงถูกนับทั้งในช่อง `automatic_pairs` และในช่อง `requiring_review`
⇒ `541 + 1,060 − 24 = 1,577`

หน้าจอแก้แล้ว — ติดหน่วย `(ใบ)`/`(คู่)` ที่ป้าย เพิ่มคำเตือนว่าห้ามบวก
และแสดงตารางกระทบยอดที่คำนวณจาก **ตัวข้อสังเกตเอง** ไม่ใช่จากยอดสรุปที่เก็บไว้
ถ้าสองอย่างไม่ตรงกัน หน้าจอจะประกาศว่า **กระทบยอดไม่ลง** แทนการแสดงตัวเลข
