# ภาพนิ่งโค้ด — สายเทียบเล่ม PDF↔PDF (RedBook Verify)

ภาพนิ่งของโค้ด ณ รุ่นที่ใช้ทดสอบจริง สำหรับบันทึกขั้นตอนของงานค้นคว้าอิสระ และให้ผู้อ่าน (คนหรือ AI) อ่านวิธีทำงานได้
ไม่ใช่รีโปพัฒนาต่อ และไม่มีประวัติ commit เดิม

- รุ่นต้นทาง: `28b7d5b` (= `d578663` + lock `287a2fe` · pdfbook-0.5.3)
- เฉพาะไฟล์ที่สาย PDF↔PDF ใช้ (`redbook/pdf_lane_app.py` และไฟล์ที่ import ต่อกัน) + หน้าเว็บ + เทสต์ของสายนี้ + เอกสารสัญญา API
- ไม่รวม: สาย Excel/T1B ฉบับเอกสาร · ชุดตรวจ reviewpack · บันทึกการรันกับข้อมูลจริง · รูปบุคคล · ไฟล์ PDF จริง
- ไฟล์ PDF ใน `tests/fixtures/synthetic_pdf` เป็นข้อมูลสังเคราะห์ทั้งหมด
- `redbook/data/book_catalog.json` เก็บเฉพาะลิงก์ทางการของเอกสารที่เผยแพร่แล้ว
- รหัสหน่วยงานในคอมเมนต์ถูกแทนด้วย `[รหัสหน่วยงาน]` (เปลี่ยนเฉพาะคอมเมนต์ ตรวจแล้วว่าโครงสร้างโค้ดเท่าเดิม)
- ไฟล์ทั้งหมดพร้อมค่า SHA-256 อยู่ใน `MANIFEST.sha256`

ทดสอบในโฟลเดอร์นี้เอง (Python 3.12 · ติดตั้งจาก `requirements.lock.txt` + pytest httpx pymupdf):

    python -m pytest -q tests
