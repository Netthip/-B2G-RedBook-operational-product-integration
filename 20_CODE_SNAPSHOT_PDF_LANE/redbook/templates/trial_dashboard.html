อ่านผลนี้อย่างไร

  • เป็นผลของเล่มนี้ ผู้ตรวจหนึ่งคน ระบบรุ่น {{ r.view.run.versions.pdfbook }} เท่านั้น ภายในหัวข้อและส่วนของเล่มที่ประกาศว่าตรวจครบ — ไม่ใช้กับเอกสารหรือหน่วยงานอื่น และไม่ใช่ความแม่นยำของระบบ
  • "พบ" นับเมื่อท่านยืนยันเอง · ข้อเสนอที่ยังไม่ยืนยันไม่นับ · พบบางส่วนนับแยก ไม่นับเป็นครึ่ง
  • ข้อมูลประกอบที่ไม่ได้จับคู่นับจำนวนเท่านั้น ไม่นับเป็นแจ้งเกิน · ระบบพบเพิ่มที่ท่านยืนยัน (ส1) รายงานแยก ไม่เพิ่มเข้าตัวหาร
  • ผลนี้ไม่ได้บอกว่าเอกสารถูกต้อง และไม่ได้วัดเวลาที่ใช้
