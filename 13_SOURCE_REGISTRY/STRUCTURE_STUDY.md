- ดาวน์โหลดเฉพาะไฟล์ที่**ไม่ครอบหน่วยผู้สมัครของ #22**

- เงื่อนไขข้างบนบังคับด้วยโค้ดแบบ fail-closed ในสคริปต์ศึกษา (repo ระบบ) และมี test ครอบ 5 กรณีปฏิเสธ

- ทุกไฟล์ผ่านด่าน #21 (`guard_file`) ก่อนเอนจินอ่าน
- ไฟล์ทั้งหมดอยู่นอก git · ไม่ commit Excel ใด ๆ

## 6. ผลกระทบต่อ eligibility ของ #22 (metadata เท่านั้น · ไม่ได้ทำ S1)

- **E2** ต้องมี Excel **ทั้งขั้นร่างและขั้น พ.ร.บ.** ของหน่วยนั้น (`FOUND` + Excel)
- ทะเบียน #27 ณ สแนปช็อตนี้: Excel **ขั้น พ.ร.บ. รายหน่วยงาน = `NOT_LISTED` ทุกปี (2568–2570)** ในส่วนที่ไล่อ่าน
  Excel ขั้น พ.ร.บ. ที่พบมีเพียง **Data Table ระดับทั้งปี** (2569/2570)
- **E3** รับไฟล์หลายหน่วยได้เฉพาะเมื่อหน้ารายการทางการระบุว่าไฟล์ครอบหน่วยนั้น
  หน้ารายการ Data Table มีเพียงชื่อปี ("ประจำปีงบประมาณ พ.ศ. …")
- ⇒ ถ้าใช้ถ้อยคำ E2/E3 ตามโปรโตคอล `1.0.0` **มีแนวโน้มว่าไม่มีหน่วยใดผ่าน** ซึ่งตาม §4.2/§10.6 = หยุดที่ S1 และส่งกลับ Gift
  การเปลี่ยนแหล่ง เกณฑ์ หรือชั้นการเทียบ ต้อง**ขึ้นรุ่นโปรโตคอล + seed ใหม่** (§11)
- ข้อนี้เป็น**ผลของแหล่งข้อมูล** ไม่ใช่ผลของเอนจิน และการที่เอนจินอ่าน Data Table ได้หรือไม่**ไม่ใช่เกณฑ์ eligibility** (คำตัดสินข้อ 6)
