# 13_SOURCE_REGISTRY — ทะเบียนแหล่งเอกสารงบประมาณทางการ FY2568–2570 (#27)

> สถานะ: **DEVELOPMENT / FORMATIVE**, ไม่ใช่ผลประเมินสุดท้าย · รุ่น `source-registry-0.1.0` · สัญญาข้อมูล `source-contract-0.1.0`

## ใช้ทำอะไร

ทะเบียนนี้บอกว่าสำนักงบประมาณเผยแพร่เอกสารชุด **ร่าง พ.ร.บ.** และ **พ.ร.บ.** ปี 2568–2570 อะไรไว้บ้าง
เป็น PDF หรือ Excel และลิงก์ยังเปิดได้หรือไม่ ณ วันที่ตรวจ
จากนั้นจับคู่เล่มที่เทียบกันได้ทั้งในปีเดียวกัน (ร่าง ↔ พ.ร.บ.) และข้ามปี
แล้วระบุตามจริงว่าคู่ไหนเทียบได้ถึงระดับใด

## แหล่งข้อมูล

- เว็บไซต์ `https://www.bb.go.th/` เฉพาะหน้าที่เผยแพร่สาธารณะ เมนู "เอกสารงบประมาณ"
- **ไม่ใช้**ไฟล์ภายใน ไฟล์ก่อนเผยแพร่ mapping ส่วนตัว หรือไฟล์ในเครื่อง
- **ไม่เก็บสำเนา PDF/Excel** เก็บเฉพาะลิงก์ทางการกับผลตรวจลิงก์
- ตรวจลิงก์ด้วยการขอ 16 ไบต์แรก (HTTP Range) เพื่อดูชนิดไฟล์ ไม่ดาวน์โหลดทั้งไฟล์
- ถ้าลิงก์ถูกส่งต่อหลายทอด (redirect) บันทึกเฉพาะ**ชื่อโฮสต์**ของแต่ละทอด
  ไม่บันทึก URL ของหน้าลงชื่อเข้าใช้ เพราะมี token

ส่วนที่ไล่อ่าน และส่วนที่**ไม่ได้**ไล่อ่าน พร้อมเหตุผล ดูได้ที่ [`SEARCH_SCOPE.md`](SEARCH_SCOPE.md)
ทั้งหมดนี้ใช้กับกติกา **หาไม่เจอ ≠ ไม่มี**

## สร้างซ้ำ

โค้ดอยู่ใน repo ระบบ (private) branch `data/27-source-registry`

```
python scripts/build_source_registry.py            # ดึงหน้าเว็บ + ตรวจลิงก์ + สร้างผลอนุพันธ์
python scripts/build_source_registry.py --derive   # ไม่ออกเน็ต · สร้างผลอนุพันธ์จากสแนปช็อตเดิม
```

ผลอนุพันธ์คำนวณจากสแนปช็อตแบบ deterministic
ส่วนผลตรวจลิงก์เปลี่ยนตามวันที่ตรวจ เพราะเว็บต้นทางเปลี่ยนได้
