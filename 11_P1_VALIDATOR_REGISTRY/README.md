## ชุดนี้คืออะไร

ทะเบียนชุดข้อมูล (dataset registry) และการออกแบบการประเมินของ **P1 Numeric Validator**
ซึ่งเป็นเครื่องมือ rule-based แบบ local-only / read-only สำหรับตรวจความสอดคล้องเชิงตัวเลข
ในไฟล์ Excel แบบฟอร์มงบประมาณ แล้วออก **รายงานข้อสังเกต** ให้ผู้ปฏิบัติตรวจสอบต่อ
(ไม่ตัดสินแทนผู้ปฏิบัติ · ไม่มี AI ในเส้นทางการตัดสิน)

## สารบัญ

| ไฟล์ | คือ |
|---|---|
| `01_REGISTRY_SCHEMA.md` | schema ของทะเบียน + สิ่งที่ทะเบียนตรวจพบ |

| `build_registry.py` | สคริปต์สร้างทะเบียน (read-only) |
| `leak_check.py` | ตัวตรวจการรั่วไหลก่อนเผยแพร่ |
| `registry.public.csv` | ทะเบียนฉบับ sanitized 50 ระเบียน |

## กติกาการเปิดเผยข้อมูลของชุดนี้

| เผยแพร่ | ไม่เผยแพร่ |
|---|---|
| แฮช · schema version · ตัวชี้วัด · รหัสกฎ · โครงสร้างทะเบียน | ไฟล์ข้อมูลงานจริงทุกชนิด |
| pseudonym ของหน่วยงาน (`A1`–`A4`) | ชื่อ/รหัสหน่วยงานจริง · ตารางเทียบ pseudonym |
| จำนวนนับ · สัดส่วน · สถานะโครงสร้าง | ยอดเงินภายในทุกจำนวน |
| ระเบียบวิธีและข้อจำกัด | path เครื่อง · ชื่อไฟล์ · โครงสร้างโฟลเดอร์ภายใน |

อัตลักษณ์จริงทั้งหมด (ตารางชื่อหน่วยงาน→รหัส · ชื่อไฟล์ mapping donor · รูปแบบคำต้องห้าม)
ถูกแยกออกจากโค้ดไปไว้ในไฟล์ local ที่ **ไม่อยู่ใน repo** — ทั้ง `build_registry.py` และ
`leak_check.py` อ่านผ่าน env `P1REG_LOCAL_CONFIG` — ถ้าไม่มีไฟล์นั้น `build_registry.py`
ยังรันได้แต่ resolve รหัสหน่วยงานไม่ได้ ส่วน `leak_check.py` จะไม่มีรูปแบบให้ตรวจเลยและจะเตือน

> เหตุผลที่ต้องแยก: ตัวตรวจการรั่วไหลที่ฝังคำต้องห้ามไว้ในตัวเอง ก็คือการรั่วไหลอย่างหนึ่ง

## เส้นแบ่งที่ห้ามข้าม

ทะเบียนนี้เป็นของ **P1 Numeric Validator เท่านั้น** — เป็นคนละเครื่องมือ คนละแบบฟอร์ม
และคนละหน่วยเงินกับสาย **T1A / T1B (RedBook Verify)** ซึ่งทะเบียนกลางจัดชุดข้อมูลกลุ่มนี้ไว้ที่
ชั้น **T3 (supplementary)** และ **T5 (archive / prior artifact)** และระบุว่าไม่ใช้ในผลหลักของสายนั้น

🔴 **ห้ามรวมคะแนน ห้ามใช้ตัวหารร่วม ห้ามอ้าง mapping ข้ามกันระหว่างสองสาย**

## สิ่งที่ยังไม่มี (ประกาศไว้ตรง ๆ)

- ยังไม่มีเฉลยผนึกใด ๆ ⇒ **ยังรายงาน Precision / Recall / F1 ไม่ได้ ณ วันนี้**
- ยังไม่มีการแยกบทบาทผู้สร้างชุดทดสอบ / ผู้พัฒนา / ผู้ให้คะแนน ⇒ **ผลใด ๆ ยังเรียกว่า blind ไม่ได้**
- `data_role` ทุกระเบียนยังเป็น `UNASSIGNED` — รอเจ้าของงานตัดสิน
